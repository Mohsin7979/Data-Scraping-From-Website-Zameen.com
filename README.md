# Data-Scraping-From-Website-Zameen.com
This project demonstrates how to scrape publicly available real estate data from Zameen.com using Python. The project uses Requests to fetch webpage content, BeautifulSoup to parse and extract information from HTML, and Pandas to organize and save the collected data into CSV files.

Technologies Used
Python
Requests
BeautifulSoup
Pandas
LXML
Google Colab
